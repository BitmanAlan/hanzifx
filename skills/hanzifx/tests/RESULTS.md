## 全新环境安装实测（2026-11-21）

测法：干净的用户目录（新建一个空的 HOME：没有 npm 缓存、没有 playwright 的浏览器缓存、没有 agent 的 skills 目录），PATH 里只有官方下载的 Node 20（v20.20.2，SHASUMS256 核对过）和系统自带的命令，外加 Homebrew 的 ffmpeg 9.0.2；从仓库 clone（提交 e1fd3bc），然后照 README 跑 `bash scripts/install_skill.sh`，再导出一条。机器同上（Apple M5 Pro，macOS 26.5），网络能连 GitHub。

| 步骤 | 结果 | 用时 |
|---|---|---|
| `git clone` | ✓ | 1 秒内 |
| `bash scripts/install_skill.sh` | ✓ 装依赖 11 个包；9 款字体全部下载并核对 sha256，做好试玩字库；doctor 全部 ✓；skill 链接到 `~/.claude/skills/cn-text-fx` | 157 秒（大部分是下载字体） |
| `node cli/export.mjs --style styles/001-variety-outline --text "这也太*好笑*了吧"` | ✓ 竖屏 MP4，101 帧，1.96 MB | 20 秒 |

占用空间：`engine/node_modules` 35 MB，字体源文件 65 MB（思源黑体两档、思源宋体两档各共用一个文件），试玩字库 15 MB，npm 缓存 15 MB。

发现的问题：

1. **浏览器**：干净的用户目录里没有锁定版本的 chrome-headless-shell，导出自动用了本机的 Google Chrome 158，doctor 也照实提示「想要逐帧结果最稳，再装锁定版本的 headless-shell」。本机连 Chrome 都没有的机器，这一步会卡住，安装脚本现在不会装浏览器。建议安装脚本加一步（或者一个开关）装锁定版本的 headless-shell，大约多下载 100 MB。
2. **字体下载**：这台机器能连 GitHub，所以没撞上。国内网络连不上 raw.githubusercontent.com 时，可以设 `CNFX_FONTS_MIRROR` 换地址，或者手动把文件放进 `engine/fonts/src/`，见 `engine/FONTS.md`「下载不下来怎么办」。实测 jsDelivr 能下 20 MB 以下的字体，思源宋体（24 MB）它不给。
3. 实测脚本本身踩过一个 bash 的坑（`$变量` 后面紧跟全角标点会被当成变量名的一部分），跟本库无关，写在这里给以后写安装脚本的人提个醒：中文紧跟变量时写 `${变量}`。
