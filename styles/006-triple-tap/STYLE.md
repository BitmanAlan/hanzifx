# 006 三连引导（Triple Tap）

| 编号 | 英文 slug | 中文俗名 | 曾用名 | 类别标签 |
|---|---|---|---|---|
| 006 | triple-tap | 三连引导 | 一键三连、点赞投币收藏、点赞收藏转发 | 互动、片尾 |

一句话：片尾或者求互动那一刻的「三连」动画。手按住点赞，圆环蓄力，三个按钮一起点亮绽放。图标全部是自己画的，透明底，叠在视频上用。

调用：`用 006 做一个三连引导，横排，透明底`。日常用默认 V1；要招牌效果，说「综艺」或者 `look=showcase`。

2026-11-19 首版。跟最初设计不一样的地方列在文末。

## 1. 本质，和它不是什么

- **本质**：把观众要做的三个动作，演成一段有手感的小动画：按住、蓄力、一起亮起来、绽放。它是叠在画面上的透明小部件，本身不是一屏内容。
- 它不是：
  - 单个点赞动画：那个只有一个按钮。
  - 账号名片卡：那个有头像、名字和关注按钮。
  - 任何平台的真实按钮：图标全部自己画，不用平台的品牌色值，不照搬平台的界面布局。

## 2. 用在哪

按两轮抖音视频测量的结论（样本少，待补），排在前面的是：**B 站横屏视频的片尾求三连（横排，16:9 主样片）**；其次是竖屏短视频片尾，或者口播中间求点赞收藏的那一刻（竖排）。两轮都没在抖音头部 vlog 里看到片尾三连。2–6 秒，画面上可以同时有别的内容。

## 3. 画面和版式

| 版式 `layout` | 三个动作（`set=auto` 时） | 排列 | 默认位置 |
|---|---|---|---|
| `row` 横排 | 点赞、投币、收藏 | 横着一排，按钮间距是直径的 0.6 倍；三个加起来太宽（超过画面宽的 70%）就自动缩 | 水平居中；竖屏在画面高度 0.66，横屏 0.72 |
| `column` 竖排 | 点赞、收藏、转发 | 竖着一列 | 画面右侧，右边缘离画面右侧 18%，给平台自己的按钮列让位；垂直居中偏下（0.52） |

每个按钮从下到上：光晕、投影、半透明深色底盘（叠在花哨的画面上也看得清）、圆环（只有横排的投币和收藏有）、图标、点亮时飘出的「+1」。按钮下面一行小字，可以再加一行数字。

质感（`material`）：默认 `candy` 亮面糖果，按钮换成底座的圆按钮零件：有厚度、白亮边、镜面高光；没点亮是灰色糖果按钮、白色实心图标，点亮那一下换成主色（投币的「¥」跟着变主色）；手按住、点下去时按钮面往下陷，点亮后弹回。`flat` 平面是上面说的半透明底盘加描线图标。

## 4. 字体

| 用途 | 字体 | 许可证 |
|---|---|---|
| 小字、数字、「+1」 | 思源黑体 Bold（Noto Sans SC，可变字体取 wght 700，登记名 `notosc-bold`） | OFL-1.1 |

备用字体链：`notosc-bold → notosc-black`。小字字号取短边的 0.028 和直径的 0.22 两者中大的那个，不会更小；数字用等宽数字。

## 5. 填充、描边和阴影

- 图标没点亮时只描线（线宽是直径的 7%，四个图标同一套线宽和圆角），点亮时填满点亮色，描边换成点亮色加深一档。
- 小字白字加深色描边（`paint-order: stroke`），叠在任何画面上都清楚。
- 光晕是点亮色的径向渐变：点亮那一下最亮，之后留一点。

## 6. 中文排版

基本不适用。三个小字各自一段、不断行，排版检查照常跑（词中间断行、行首标点都查）。数字用等宽数字，内容变了宽度也不会跳。

## 7. 配色预设

全部用全库统一的 8 个颜色角色。这个风格里每个角色管的是：

| 角色 | 在 006 里管什么 |
|---|---|
| fill | 没点亮时的图标线条 |
| fill2 | 中间那个按钮（横排投币、竖排收藏）点亮后的颜色；第三个按钮（横排收藏、竖排转发）用 accent 和 fill2 对半混的颜色 |
| inner | 蓄力圆环 |
| outer | 小字描边、点亮后图标的描边、手的描边 |
| shadow | 按钮投影 |
| accent | 点赞点亮后的颜色 |
| bg | 按钮底盘（半透明） |
| sub | 小字和数字 |

| 编号 | 名字 | 适合 |
|---|---|---|
| C1 | 暖粉 | 默认，二次元、生活 |
| C2 | 极简白 | 画面已经很花、只要一点提示的时候 |
| C3 | 红黄 | 带货、高能 |
| C4 | 深色版 | 叠在白底、浅色画面上 |

所有配色都不用平台品牌色的精确色值。11-19 审查后改了两处：C1 点赞的粉，从 #FF5A8A 换成 #F55A6E，原来的颜色离 B 站新版粉只差约 6.9，配上「点赞 投币 收藏」横排太像；C3 收藏的黄，从 #FFCC00 换成 #FFB300，原来的颜色离抖音收藏的黄只差约 3.8。对照用的平台色值是凭记忆的公开数值，还要拿实图确认。11-21 横排的收藏改成跟竖排转发一样的 accent、fill2 对半混：原来跟投币同色，亮起来像两枚一样的金币，现在三个是粉、金、橙（C2 极简白三个本来就都是白）。

## 8. 动效：入场、停留、出场

横排 `row`，R1 全程 3.0 秒：

| 段 | 时间 | 做法 |
|---|---|---|
| 入场 | 0–0.30 秒 | 三个按钮从下往上弹进来，逐个错开 0.06 秒 |
| 按住 | 0.30–0.70 秒 | 手从右下方伸进来按住点赞，点赞被压小一点、左右抖（幅度是直径的 3%，每秒 12 次） |
| 蓄力 | 0.70–1.50 秒 | 投币、收藏外面的圆环从 12 点方向顺时针走满一圈；三个按钮越抖越厉害 |
| 绽放 | 1.50–1.95 秒 | 三个一起点亮，放大到约 1.18 倍再弹回，带一点左右摆；每个按钮爆出一组粒子（爱心、硬币、星星），飘出「+1」；手收回去 |
| 停留 | 1.95–2.70 秒 | 按钮保持点亮，轻轻呼吸 |
| 出场 | 2.70–3.00 秒 | 往下缩小消失，逐个错开 0.04 秒 |

竖排 `column`，R1 全程 2.8 秒：入场 0.3 秒 → 手从左下方伸进来，从上往下依次点三个按钮（每 0.45 秒一个），点一个亮一个、跳一下、爆一小组粒子 → 停留 → 出场 0.3 秒。

造型预设：**V1 日常**（默认）；**V3 招牌**：粒子更多，加放射光（越往外越淡）、冲击波、彩纸，停留时有小爱心从点赞上方往上飘。

节奏预设：R1 标准；R2 快（全程压到约 2 秒）；R3 挂着（停留段多 3 秒，适合口播中间一直挂着）。

## 9. 时间和卡点

`timeline.json` 里每个按钮有 `enter`（开始入场）、`lit`（点亮）、`exitStart`、`exitEnd`；`beats` 里每个按钮点亮那一刻标了 `lit`，剪辑时在这里配一声「叮」。本风格自己不带声音。

## 10. 参数和默认值

| 参数 | 默认 | 说明 |
|---|---|---|
| `text` | 点赞 投币 收藏 | 三个小字，用空格分开；竖排没改过时自动换成「点赞 收藏 转发」 |
| `look` | V1 | V1 日常 / V3 招牌 |
| `layout` | row | row 横排 / column 竖排 |
| `set` | auto | 横排点赞投币收藏、竖排点赞收藏转发；也可以指定 coin 或 share |
| `size` | 0.11 | 按钮直径占画面短边，0.07–0.16 |
| `hand` | 开 | 有手才像在教你点 |
| `plusOne` | 开 | 点亮时飘「+1」；填了 `counts` 时不飘，免得信息重复 |
| `counts` | 空 | 三个数字，用空格分开；默认不显示，不编造数字 |
| `particles` | 14 | 三个按钮一共大约多少个粒子 |
| `flair` | 0 | 招牌强度，V3 自动设成 1 |
| `x`、`y` | 空 | 空着就按版式自动放 |
| `seed` | 7 | 粒子、放射光、飘爱心的随机全走种子 |

## 11. 坑

1. **撞平台的设计**：图标太像某家平台的，就有商标和仿冒的风险。发布前要拿各平台的公开截图逐个比一遍（截图只用来比，不放进仓库），像了就改。**还没做，见第 13 节 `brand-lookalike`。**
2. **竖排被平台按钮盖住**：竖排默认右边缘离画面右侧 18%，平台按钮区按经验值是右侧 15%，中间只有 3% 的空隙。点亮时光晕和冲击波会外扩，V3 竖排实测会进按钮区 57 像素（只出提示）。按钮区要等手机 App 截图量准了再定。
3. **不要给整组设透明度**：整组按钮做淡入淡出时，Chrome 会根据「透明度是不是一直在变」决定要不要单独提一层来画，提没提层，画出来的取整差一点，乱序渲染逐帧就对不上（2026-11-19 实测踩过）。所以入场、出场只靠缩放，手的淡入淡出写在它自己的填色透明度上，光晕单独放一层。
4. **圆环的起点和方向**：必须从 12 点方向、顺时针走。SVG 的圆默认从 3 点开始，要先转 -90°。
5. **小尺寸看不清**：按钮直径小于短边的 0.07 时，手和图标会糊在一起，参数下限就设在 0.07。
6. **投币图标**：圆里再套一圈内环加「¥」，缩小以后像一张猫脸（11-19 看样片发现），现在只留一个粗的「¥」。

## 12. 可变空间

- 随便改不会坏的：配色、横排竖排、手指开关、「+1」开关、数字、节奏、按钮大小（0.07–0.16）、粒子数（30 以内）。
- 改了会变味、要小心的：去掉蓄力的圆环，「三连」的手感就没了；粒子开到 30 个以上会显脏。
- 改到这一步就是别的元素了：只留一个按钮，是单个点赞动画；换成头像加关注按钮，是账号名片卡。

## 13. 检查

| 检查 | 结果（2026-11-19） |
|---|---|
| 描边被画面边缘切掉 | 横排、竖排 × V1、V3 × 竖屏、横屏共 8 种，逐帧查过，都没贴边 |
| 缺字 | 不缺，实际用的是思源黑体（浏览器报名「Noto Sans SC Thin」，是固定字重后 name 表没跟着改，字形实际是 700） |
| 安全区 | 只出提示：V1 竖排进右侧按钮区 29 像素，V3 竖排 57 像素；横排都没进 |
| 乱序渲染逐帧一致 | 4 路打乱顺序和单路顺序比对：横排 V1、V3，竖排 V1、V3 都一致；V3 竖排另外连跑 4 轮，也都一致。中间有一次 V3 竖排对不上，是 4 种组合连着跑时出现的，之后 5 轮都没再出现，后来查明是浏览器局部重画的问题，底座默认关掉局部重画以后没再出现 |
| `min-size` | 参数下限 0.07，超出范围会被夹住 |
| `brand-lookalike` | **还没做完**：图标已经审过，都是通用画法；颜色撞平台的两处已经换掉（见第 7 节）。还差拿 B 站三连按钮、抖音右侧按钮列、小红书底栏的实图逐个比，还没做 |

## 14. 导出和发布

- 透明底优先：`--bg transparent`，导出 ProRes 4444 的 .mov 和带 alpha 的 WebM，要逐帧图就加 PNG 序列。
- meta.json 的 `exportDefaults` 已经把透明底设成默认，不用自己加 `--bg transparent`。
- 一键样片（设计单写的「深色画面上叠一个横排、一个竖排」）还没做。

## 15. 出处和许可证

- 字体：思源黑体 Noto Sans SC，OFL-1.1。
- 图标（点赞、投币、收藏、转发、手）：本项目自己画的，随代码用 MIT。
- 参考效果：国内视频平台常见的片尾「三连」引导，只参考了动作节奏，没用平台的图标、品牌色和布局。

## 跟最初设计的差别

1. 配色角色名换成全库统一的 8 个，对应关系见第 7 节。C2 极简白：设计单是靠透明度区分点亮前后，现在改成点亮前只描线、点亮后填满，同样能看出区别。
2. 入场、出场不做整组淡入淡出，只靠缩放（理由见第 11 节第 3 条）。
3. 新加了「+1」（`plusOne`，默认开）。
4. 竖排的手改从左下方伸进来，粒子主要往左上方飞，免得伸进右边的平台按钮区。
5. 竖排时间改成每 0.45 秒点一个，全程照样是 2.8 秒。
6. 新加了 V3 招牌造型（放射光、冲击波、彩纸、飘爱心）。设计单写的时候还没有「每个风格配一个招牌预设」这条规矩。
7. 横排在竖屏里默认放在画面高度 0.66，不是 0.7。原因是放在 0.7 时，往下落的粒子会掉进底部文案区。
8. 「透明底默认开」现在做不到，要导出时自己加参数（见第 14 节）。

**11-19 审查后又改了**：小字挪到粒子上面一层（竖排时飘过的粒子会挡住「点赞」）；填了数字时不飘「+1」；V3 彩纸散开的范围收小一点；补了一条 16:9 横排主样片（`demo/006_V1_横排_横屏.mp4`）。
