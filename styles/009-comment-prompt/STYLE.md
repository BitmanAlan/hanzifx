# 009 「评论区告诉我」引导（Comment Prompt）

| 编号 | 英文 slug | 中文俗名 | 曾用名 | 类别标签 |
|---|---|---|---|---|
| 009 | comment-prompt | 评论区告诉我 | 求评论、评论引导、评论区见 | 互动、评论、口播结尾 |

一句话：口播结尾求评论。评论图标弹出，对话泡里三个点一跳一跳像在输入，问题一个字一个字打出来，最后出「评论区告诉我」和一个往下点的箭头。

调用：`用 009 在结尾问一句「你遇到过这种情况吗？」`。默认透明底。

2026-11-20 首版。

## 1. 本质，和它不是什么

- **本质**：用「对方正在输入」这个大家都熟悉的样子，把一句提问演出来，让观众觉得是在跟他对话，顺手去评论区回一句。
- 它不是：010 评论卡（那个是展示一条评论）；016 投票条（那个是二选一）；任何平台的评论按钮（图标、对话泡、箭头都是自己画的）。

## 2. 用在哪

口播结尾的提问、抛一个话题让大家站队、征集下期选题。适合发哪是推断，见 meta.json 的 `platforms`。

## 3. 画面和版式

- 左边一个圆形评论图标，右边一个对话泡，尾巴指向图标；下面一行小字（默认「评论区告诉我」）加一个往下的箭头，小字垫一块半透明深色底，叠在花哨的画面上也看得清。
- 整组水平居中，竖屏默认在画面高度 0.66，横屏 0.7。
- 问题最多两行，按词断行；放不下就缩字号，最多缩到 70%。
- 质感（`material`）：默认 `candy` 亮面糖果，评论图标的圆换成底座的圆按钮零件，对话泡换成底座块零件（有厚度、白亮边、上沿高光，宽高照旧跟着打字长；浅色泡顶面只压暗 5%，侧壁混一点强调色、底下一道深边线），尾巴也带一截侧壁；底下小字垫的半透明底换成不透明的糖果胶囊条（字是浅色用深色胶囊，C4 字是深色用浅色胶囊）；`flat` 平面是原来的扁平图标、对话泡和半透明小字底。招牌冒出来的小泡两种质感一样。

## 4. 字体

思源黑体 Bold（`notosc-bold`），备用思源黑体 Black。OFL-1.1。

## 5. 填充、描边和阴影

对话泡和图标都是实色，带一点下移的硬投影（不用模糊）。底下的小字带深色描边。

## 6. 中文排版

- 按词断行，用底座的分词，跟检查用同一套。比如「普通人学AI，／最该先学哪一样？」。
- 行尾的逗号、句号挤半格；问号、感叹号不挤（跟 010 一样）。
- `*关键词*` 换成强调色。

## 7. 配色预设

| 编号 | 名字 | 适合 |
|---|---|---|
| C1 | 白泡橙 | 默认 |
| C2 | 紫泡 | 年轻、活泼 |
| C3 | 深色 | 画面偏亮，或者要高级一点 |
| C4 | 便签黄 | 叠在浅色画面上（底下的小字改成深色） |

## 8. 动效：入场、停留、出场

| 段 | 做法 |
|---|---|
| 入场（约 0.45 秒） | 评论图标弹出；对话泡从图标那边长出来 |
| 正在输入（默认 0.7 秒，`typing` 可调） | 泡里三个点依次一跳一跳 |
| 打字 | 问题一个字一个字出现（每字约 0.045 秒）；**泡跟着打出来的字一点点变宽**，两行的问题打到第二行泡才变高，字始终在泡里上下居中 |
| 停留（默认 1.8 秒，`hold` 可调） | 小字和箭头弹出，箭头往下一点一点；泡轻轻上下浮 |
| 出场（约 0.3 秒） | 整组缩小消失，缩到 0.2 以下就隐藏 |

造型：V1 日常；V3 招牌（对话泡弹得更厉害，问题打完冒几个小对话泡，箭头跳得更欢）。节奏：R1 标准、R2 快、R3 挂着（停留 2.5 倍，适合口播最后一直挂着）。

## 9. 时间和卡点

`timeline.json` 的 `beats` 里有「开始打字」（可以配键盘声）和「评论区告诉我出现」（配「叮」）。

## 10. 参数和默认值

| 参数 | 默认 | 说明 |
|---|---|---|
| `text` | 你遇到过这种情况吗？ | 问题，最多两行 |
| `label` | 评论区告诉我 | 底下的小字 |
| `look` | V1 | V1 日常 / V3 招牌 |
| `size` | 0.13 | 评论图标的直径，占画面短边；问题的字号跟着它走 |
| `typing` | 0.7 | 「正在输入」跳多久（秒），0 就是不跳直接打字 |
| `hold` | 空 | 停留秒数，空着是 1.8 秒 |
| `x`、`y` | 空 | 空着就自动 |

## 11. 坑

1. **泡一出来就是最终宽度会很假**：第一版泡一出来就是整句话的宽度，三个点的时候里面空一大截。现在泡跟着字长。
2. **字要跟着泡居中**：泡跟着打字变高以后，第一版字还是按两行的位置排，打第一行时字顶出了泡。现在字的整组跟着泡的高度一起居中。
3. **不仿平台的评论图标**：图标是一个圆角对话框加两道横线，自己画的。

## 12. 可变空间

- 随便改不会坏的：配色、问题、小字、大小、位置、输入和停留时长。
- 改了会变味的：把 `typing` 设成 0（少了「对方正在输入」的感觉）。
- 改到这一步就是别的元素了：换成展示一条网友评论，是 010；换成两个选项，是 016。

## 13. 检查

| 检查 | 结果（2026-11-20） |
|---|---|
| 词中间断行、行首标点 | 默认问题和两行的测试问题，竖屏、横屏都过 |
| 描边被画面边缘切掉、缺字、闪烁 | 都没有问题 |
| 乱序渲染逐帧一致 | V1、V3 × 竖屏、横屏 × 两种背景，加上两行的问题，各 2 轮全部一致 |
| 安全区 | 只出提示：竖屏进了右侧按钮区约 89 像素（经验值，未实测） |
| brand-lookalike | 还没拿平台截图比 |

## 14. 导出和发布

默认透明底（`exportDefaults`），导出带透明通道的 .mov（ProRes 4444）和 .webm（VP9）。

## 跟最初设计的差别

1. 新加了「泡跟着字长」和「打字」这一段：设计只写了「对话泡弹出、省略号一跳一跳」，现在省略号之后接着把问题打出来，更像真的在输入。
2. 底下的小字和箭头是新加的，直接告诉观众去哪评论。
3. 招牌造型 V3 是新加的。
