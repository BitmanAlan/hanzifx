# 行为准则 / Code of conduct

在这个项目的 issue、讨论区、PR 和社区群里，请做到：
In issues, discussions, pull requests and community chats, please:

- 对人友善，对事直接。批评代码和设计可以，攻击人不行。
  Be kind to people and direct about the work. Criticize code and design, never people.
- 不发骚扰、歧视、色情、暴力内容，不公开别人的隐私。
  No harassment, discrimination, sexual or violent content, and no sharing of anyone's private information.
- 不发广告和与项目无关的推广。
  No spam or unrelated promotion.
- 别把别人的作品当成自己的，用到别人的素材要写明出处和许可证。
  Don't pass off others' work as your own; credit sources and licenses.

违反的内容会被删除，屡次违反的账号会被禁止参与。要举报，用 GitHub 的举报功能，或者走 `SECURITY.md` 里的私密报告渠道。
Content that breaks these rules will be removed, and repeat offenders will be blocked. Report via GitHub's reporting tools or the private channel in `SECURITY.md`.
